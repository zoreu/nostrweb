# Nostr Web

**Nostr Web** is a decentralized web interface that allows users to **access and publish static websites directly through the Nostr network**.

Instead of relying exclusively on traditional web servers and centralized hosting, Nostr Web uses Nostr as a decentralized layer for distributing and accessing static web content.

## 🌐 Web Interface

You can access the Nostr Web interface directly from your browser:

**https://zoreu.github.io/nostrweb/**

The interface allows you to test and access **P2P website addresses on the Nostr network**.

## 🧩 How It Works

Nostr Web uses the Nostr protocol as a communication and distribution layer for static websites.

A static website can be published to the Nostr network and then accessed using its Nostr address.

The general flow is:

```text
Static Website
      │
      ▼
   Nostr Web
      │
      ▼
 Nostr Network
      │
      ▼
 Decentralized Relays
      │
      ▼
   Nostr Web
      │
      ▼
   Web Browser
```

The Nostr Web interface acts as a gateway between the traditional web browser and websites distributed through the Nostr network.

## 🌐 Accessing a P2P Website

To access a P2P website:

1. Open the Nostr Web interface:

   **https://zoreu.github.io/nostrweb/**

2. Enter a supported Nostr website address.

3. Submit the address.

4. Nostr Web retrieves the required website data through the Nostr network.

5. The static website is loaded directly in your browser.

## 🏗️ Project Concept

Nostr Web explores the idea of using **Nostr as a decentralized web infrastructure**.

Traditional static websites generally depend on centralized infrastructure:

```text
Browser
   │
   ▼
Web Server
   │
   ▼
Website Files
```

Nostr Web introduces a decentralized alternative:

```text
Browser
   │
   ▼
Nostr Web
   │
   ▼
Nostr Relays
   │
   ├── Relay A
   ├── Relay B
   ├── Relay C
   └── Relay D
```

This approach allows static web content to be distributed through the Nostr ecosystem instead of depending entirely on a single centralized hosting provider.

## 🔐 Decentralization

Nostr Web does not attempt to replace the entire traditional web.

Instead, it provides an experimental architecture for publishing and accessing **static websites through Nostr**, combining familiar web technologies with decentralized communication.

Because Nostr uses multiple independent relays, applications can potentially retrieve content from different locations instead of depending on a single centralized server.
